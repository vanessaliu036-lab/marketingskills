## Source-selection rule

Use the smallest useful set.

- Premium visual direction → Refero + Minimal Gallery
- Cinematic / scroll / 3D → Scrolltide
- Production components → shadcn + one specialist library
- Motion → Motion Primitives / Kinetics / Aceternity / Magic UI
- Tiny microinteraction → MicroKit / Uiverse
- Maps → mapcn
- Text-only animation → CSS Text Effects
- Glass/refraction → Liquid Glass
- 404 / fallback → 404s.design
